Frequently Asked Questions

Everything you need to know about ChatBridge architecture and privacy.

Is ChatBridge 100% free and open-source? +
Yes! ChatBridge is completely open-source under the MIT License. You can inspect the source code, contribute, or build custom extractors directly on GitHub.
Where are my API keys and conversations stored? +
Everything is stored exclusively in your browser's local chrome.storage.local. ChatBridge has zero remote servers, zero analytics, and zero external telemetry.
Can I use ChatBridge without entering any API keys? +
Yes! ChatBridge features powerful built-in local heuristic modes (Smart Mode, Aggressive Mode, Full Chat, User Only) that operate instantly without any AI API keys or network requests.
Which browsers are supported? +
ChatBridge is built on Manifest V3 and runs on Google Chrome, Brave, Microsoft Edge, Opera, Arc, and any Chromium-based browser.
